# Goya GraVid 2026

Aplicación React + Vite basada en el componente `tsx` original.

## Requisitos

- Node.js 18+

## Ejecutar en local

```bash
npm install
npm run dev
```

Abre la URL que imprime Vite (normalmente `http://localhost:5173`).

## Build de producción

```bash
npm run build
npm run preview
```
